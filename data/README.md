## Expected file

Place the downloaded archive in the Colab/Jupyter working directory as:

```text
adult.zip
```

The notebook extracts `adult.data` automatically.

Do not commit large raw dataset files unless you have confirmed that doing so is appropriate under the dataset's terms.
